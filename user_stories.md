1. Admin User Stories
Story 1 (User Management): As an Admin, I want to create and deactivate Doctor and Patient accounts, so that only authorized medical staff and real patients have system access.

Story 2 (Role-Based Access): As an Admin, I want to assign specific roles and permissions, so that confidential patient data remains protected from unauthorized roles.

Story 3 (System Audit): As an Admin, I want to view system log reports and clinic metrics, so that I can monitor daily operational efficiency and security compliance.

2. Doctor User Stories
Story 1 (Schedule Management): As a Doctor, I want to set and update my weekly availability hours, so that patients can only book open time slots.

Story 2 (Appointment Queue): As a Doctor, I want to view my daily schedule and patient list, so that I can prepare for upcoming consultations effectively.

Story 3 (Prescriptions & Notes): As a Doctor, I want to add digital prescriptions and consultation notes to a patient's file, so that their medical history remains updated.

3. Patient User Stories
Story 1 (Appointment Booking): As a Patient, I want to search for available doctors and book an appointment, so that I can receive medical care at a convenient time.

Story 2 (Managing Bookings): As a Patient, I want to cancel or reschedule an existing appointment, so that I can update my booking if my schedule changes.

Story 3 (Medical Records): As a Patient, I want to view my past prescriptions and appointment history, so that I can keep track of my medical treatment plans.
