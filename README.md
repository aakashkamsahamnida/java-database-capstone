# Smart Clinic Management System

A robust capstone project demonstrating microservice architecture readiness using Spring Boot, MySQL, MongoDB, Docker, and GitHub Actions.

## 🛠️ Tech Stack & Architecture
* **Backend:** Java 17, Spring Boot 3.x, Spring Data JPA, Spring Data MongoDB
* **Relational DB (MySQL):** Core operational entities (Users, Appointments)
* **NoSQL DB (MongoDB):** Flexible document store for Prescriptions and Medications
* **DevOps & CI/CD:** Docker, Docker Compose, GitHub Actions
